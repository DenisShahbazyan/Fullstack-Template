# Бэкапы — особенности проекта

Проектный файл скилла `backups`: в каждом проекте свой. При копировании шаблона в новый проект — заполнить.

Решение и причины — [ADR 0001](../../../docs/DECISIONS/0001-postgres-backups.md) (Postgres).

## Имена

| Что | Значение |
| --- | --- |
| Stanza pgBackRest | `main` |
| Скрипты в `docker/postgres/bin/` | `pg-archive-push`, `pg-backup`, `pg-backup-scheduler`, `pg-restore-check` |
| Каталог на сервере | `/home/<SERVER_USER>/<DOCKER_IMAGE_NAME>` |

Имена шаблона менять не нужно: stanza живёт в своём бакете бэкапов проекта.
